# ClipMotion — logos et visuels explicatifs

14,794 fichiers SVG avec transparence, dont 6,461 variantes de logos, 8,313 pictogrammes et 20 schémas originaux. Un même logo peut exister en variantes couleur, monochrome et/ou pictogramme selon les collections.

## Utiliser le catalogue

- catalogue.json et catalogue.csv relient chaque SVG à ses tags, mots-clés FR/EN, alias, dimensions, source et licence.
- Pour un logo, rechercher une marque explicite ou un alias, puis choisir une variante adaptée. Le mot-clé ChatGPT retrouve le logo OpenAI, identifié comme tel dans le catalogue. La collection inclut des SVG Google Gemini, Claude et Shopify.
- Pour une scène explicative, chercher d’abord par catégorie et usage, puis comparer les mots-clés. Exemple : « hausse » / growth → graphiques, « connecter deux apps » / integration → schéma ou flèche.
- Utiliser le SVG comme calque au-dessus du plan principal. Les pictogrammes monochromes currentColor peuvent être recolorés par l’application. Les SVG de schémas ont des textes français modifiables.
- Conserver la mention de licence applicable. Les licences de collections et les éventuelles conditions par logo figurent dans les sources et le dossier licences. Les marques restent soumises aux règles de leurs titulaires. Une illustration d’intégration ne doit pas suggérer un partenariat non établi.
